# GoSleep · 呼吸频率调制催眠 APP

基于专利 **CN112972862A《催眠音乐控制方法、装置、计算机设备和存储介质》**（申请号 201911282642，发明人：刘涛、刘志雄）实现的睡眠辅助手机 APP（Flutter，支持 Android / iOS）。

## 一、专利算法 → APP 实现映射

| 专利要素 | 专利方案 | 本 APP 实现 |
|---|---|---|
| 呼吸频率采集 | UWB 脉冲雷达检测胸腔起伏（呼吸频率 + 起伏度） | **麦克风拾取呼吸音频**：16kHz PCM → 32ms 窗 RMS 包络 → 去趋势 → 自相关测频（4~30 次/分） |
| 催眠音乐 | 白噪声类音景（海浪、下雨声），节奏与输出频率一致 | Web 式实时程序化合成（粉噪 + 滤波 + 浪涌包络），**波浪周期 = 60/输出频率 秒**；三种音景：海浪 / 细雨 / 溪流 |
| 同步跟随 | 输出频率 = 当前呼吸频率 | 校准 1 分钟得 Fa → Fb = Fa，开始播放 |
| 诱导降频 | 每预设时间 T1（默认 10 分钟）评估：Fa > 预设呼吸值(16) 且 ≤ Fb → Fb −= 步长(1) | `PatentEngine._evaluate()` 完整实现 |
| 重新同步 | Fa > Fb（呼吸不减反增）→ 重新 Fb = Fa | 同上 |
| 深睡判定停止音乐 | Fa ≤ 16 次/分 且 胸腔起伏 ≤ 8mm → 停止音乐 | Fa ≤ 预设呼吸值 且 幅度指数 ≤ 预设起伏值，**持续 60 秒**（防瞬时误判）→ 淡出停止 |
| 参数取值范围 | 预设呼吸值 12~18、步长 1~2、起伏值 4~10mm | 设置页开放，默认与专利一致 |

### 幅度指数说明（与专利 8mm 阈值的衔接）

麦克风无法直接测得胸腔起伏毫米数。APP 以**校准期（清醒 1 分钟）呼吸声包络幅度为基准**做饱和映射：

- 清醒呼吸幅度 → 约 **10.4**（mm 等效指数）
- 呼吸声幅度降至清醒的一半 → 约 **7.9**，即低于专利 8mm 深睡阈值

即"呼吸变浅到清醒时的一半"≈ 满足专利的起伏 ≤ 8mm 条件。设置页可调灵敏度（0.5×~2×）。

### 与专利的差异 / v1 扩展（诚实声明）

1. **采集方式**：UWB 雷达 → 麦克风音频估算（手机即可运行，无需外设；远距离弱信号下精度有限，界面有信号质量指示）。
2. **深睡判定加 60 秒持续条件**：防止一次瞬时误判就停止音乐（专利为即时判定）。
3. **向下跟随补全**：专利未明确"Fa ≤ 预设值 但 Fa < Fb"时的处理，v1 做向下跟随（音乐节奏不快于用户呼吸）。
4. **演示加速 60×**：设置页开关，把 T1 评估周期压缩 60 倍便于快速演示算法闭环（校准与深睡持续判定仍按真实时间）。

## 三、构建步骤

本仓库只包含 `lib/`、`test/`、`pubspec.yaml`（跨 Flutter 版本最稳）；平台目录（android/ios）用 Flutter 脚手架生成：

```bash
# 0) 安装 Flutter SDK（>=3.10，含 Dart 3）并 flutter doctor 通过

# 1) 生成平台目录（不会覆盖已有 lib/pubspec）
flutter create . --project-name gosleep --platforms android,ios

# 2) 拉取依赖
flutter pub get

# 3) 权限补丁（见下）

# 4) 连接手机运行
flutter run
```

### 权限补丁（必须）

**Android** — `android/app/src/main/AndroidManifest.xml`，在 `<application` 标签**之前**加：

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO"/>
```

**iOS** — `ios/Runner/Info.plist` 的 `<dict>` 内加：

```xml
<key>NSMicrophoneUsageDescription</key>
<string>用于采集呼吸声以估算呼吸频率（催眠音乐算法的输入）</string>
```

### 运行测试（验证专利算法实现）

```bash
flutter test
```

测试覆盖：专利实施例 2 数值流、重新同步分支、低质量样本忽略、演示加速、样本过期顺延、自相关测频精度（12/18/24 次/分）、直流/慢漂移抑制、幅度映射与 8mm 阈值衔接。

## 四、使用说明

1. **放置手机**：床头、麦克风朝向口鼻方向 30~50 厘米，环境尽量安静（无电视/他人说话声）。
2. **开始催眠**：点击"开始催眠"，正常呼吸。前 1 分钟为校准（采集呼吸频率），界面显示进度。
3. **同步跟随**：校准完成即播放与您呼吸同节奏的音景（如海浪），波浪动画与音乐节奏一致。
4. **诱导降频**：之后每 10 分钟，APP 检查您的呼吸：若仍偏快则将音乐节奏下调 1 次/分，引导呼吸逐步变慢；若呼吸反而变快，则重新跟随。
5. **深睡停止**：呼吸 ≤ 16 次/分 且 呼吸声明显变浅并持续 1 分钟 → 判定深睡，音乐淡出停止。
6. **查看报告**：报告页展示呼吸频率曲线（Fa 实测 / Fb 音乐节奏）、幅度指数曲线、降频与重同步标记、入睡用时及历史会话。

**提示**：
- 会话期间 APP 保持屏幕常亮（保证麦克风持续采集，暗色界面减少干扰）；
- 首次使用若"信号过弱"，请调近手机或调高设置中的幅度灵敏度；
- 演示场景可打开设置页"演示加速（60×）"，几分钟内即可走完整个算法闭环。

## 五、已知平台限制

- **锁屏/后台麦克风**：Android 11+ 与 iOS 在应用退后台且无前台服务时可能暂停麦克风采集（音乐播放可继续）。v1 采用屏幕常亮策略规避；整夜后台采集需要前台服务（`foregroundServiceType=microphone`），列入 v2。
- **精度**：远距离呼吸声很弱，若信噪比不足，APP 会显示"信号较弱/过弱"并不采用该时段数据（评估自动顺延），不会错误降频。
- **非医疗声明**：本应用为助眠工具，不构成医疗建议；如有睡眠障碍请咨询医生。
